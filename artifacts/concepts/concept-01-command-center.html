01 · Командный центр

Идея: процессная ориентация над коллекцией; пользователь сначала видит положение очереди, затем объекты.

Плюсы: быстрый situational awareness, таблица остаётся главной. Минусы: верхняя полоса отнимает одну строку. Риск: серверные counts потребуют контракта; в production допустимы только имеющиеся totals.

Audit / Migration: устраняет разрозненность текущего toolbar; мигрируется по слоям — shell → tabs/tools → process strip → table.
