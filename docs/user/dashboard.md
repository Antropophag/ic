# Персональные очереди заявок

Версия инструкции: 06.08.2026. Версия приложения: 0.1.0.

## Назначение

Блок «Требуют вашего внимания» расположен над реестром и показывает заявки, в
которых вы можете выполнить конкретное следующее действие. Это не общая
статистика по статусам: состав блока зависит от ваших ролей, активности и
назначений. Если применимых рабочих категорий нет, блок не отображается.

## Работа с очередью

1. Выберите категорию, например «Назначить исполнителя» или «Проверить СБ».
2. Ниже откроется тот же реестр, отфильтрованный сервером по выбранному действию.
3. Откройте заявку и выполните действие в её карточке.
4. При возврате в реестр список и счётчики обновятся.

Выбор категории переключает вкладку на «Все заявки» и первую страницу. Поиск и
статусный фильтр применяются поверх выбранной очереди, сортировка сохраняется.
Повторное нажатие на активную категорию снимает её.

## Как читать числа

Число показывает точный объём всей персональной очереди, а не только текущую
страницу реестра. Поиск и статусный фильтр на него не влияют. Если у пользователя
несколько процессных ролей, одна заявка может одновременно требовать разных
действий и учитываться в нескольких категориях; поэтому числа не следует
складывать как количество уникальных заявок.

Обновление выполняется при входе, возврате из карточки и после изменения заявки.
На первом этапе автоматического live-обновления нет. Если загрузить очереди не
удалось, уже загруженный реестр продолжает работать; повторите запрос кнопкой в
блоке.
