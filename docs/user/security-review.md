# Контроль СБ

Версия инструкции: 30.07.2026.

## Для сотрудника СБ

На этапе «Контроль СБ» доступны два действия:

- «Согласовать и завершить» — заявка получает статус «Заявка выполнена»;
- «Вернуть в работу» — заявка возвращается на доработку.

Нажатие любой из кнопок открывает окно подтверждения — решение
применяется только после повторного нажатия внутри этого окна; кнопка
«Отмена» закрывает окно без изменений.

Для возврата обязателен комментарий с причиной: он сохраняется в истории
заявки. После возврата назначения исполнителя и эксперта не меняются, а
новая редакция заключения снова проходит контроль СБ.

Если решение сохранилось, но карточка не обновилась сразу, не нажимайте
кнопку повторно — откройте заявку заново из реестра и проверьте статус.
