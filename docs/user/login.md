# Вход в портал

Версия инструкции: 08.08.2026.

На странице входа отображается декоративный фон с плавными синими линиями,
которые реагируют на движение указателя. Анимация не влияет на поля логина и
пароля и не изменяет порядок входа в портал.

При любой ошибке авторизации линии плавно меняют цвет с синего на красный. При
следующей попытке входа фон возвращается к синему цвету.

Если в операционной системе включено уменьшение движения, фон остаётся
статичным. При увеличенном масштабе страницы форму можно прокручивать как
обычно.
