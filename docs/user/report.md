# Загрузка отчёта испытаний

Версия инструкции: 28.07.2026.

## Для исполнителя

1. Откройте заявку в статусе «Заявка в работе».
2. В разделе «Документы» нажмите «Загрузить отчёт испытаний».
3. Выберите файл PDF размером до 10 МБ.

Первая загрузка переводит заявку в статус «Подготовка заключения». Повторная
загрузка на этом же этапе создаёт новую версию отчёта и не удаляет предыдущую.

До завершения заявки отчёт виден только участникам процесса: исполнителю,
руководителю, назначенному эксперту и сотрудникам СБ.
