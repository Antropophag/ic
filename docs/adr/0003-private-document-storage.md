# ADR 0003: закрытое версионное хранилище документов

- Статус: принято
- Дата: 28.07.2026

## Контекст

Вложения содержат внутренние документы и не должны быть доступны через web root,
исходное имя или предсказуемый URL. Замена файла не должна уничтожать историю.
Рабочий контур разворачивается on-premise без обязательного S3-сервиса.

## Решение

- бинарные данные хранятся в отдельном persistent Docker volume вне web root;
- путь строится только из криптографически случайного 256-битного ключа;
- исходное имя, MIME, размер и SHA-256 сохраняются в MariaDB;
- логический документ определяется заявкой и исходным именем, повторная загрузка
  создаёт следующую неизменяемую версию;
- загрузка проверяет серверный MIME, расширение, размер, активность пользователя
  и этап заявки;
- скачивание выполняется только контроллером после проверки активного профиля;
- аудит содержит идентификаторы документа и версии, но не содержимое и путь.

## Последствия

БД и volume документов необходимо резервировать и восстанавливать на одну точку
времени. Файл, записанный до неуспешного завершения транзакции, удаляется. При
аварийном разрыве процесса возможные orphan-файлы должны выявляться отдельной
регламентной проверкой. Переход на S3-совместимое хранилище потребует новой
реализации storage-адаптера, но не изменения API и модели метаданных.
