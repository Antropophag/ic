# ADR 0001: On-premise-first архитектура

- Статус: принято
- Дата: 2026-07-28

## Контекст

Корпоративные рабочие места не имеют доступа к серверам разработчика. Исходный
код размещается в локальном GitLab предприятия, а приложение эксплуатируется
в корпоративной сети и через FortiClient VPN.

## Решение

Приложение, сборка и эксплуатация не зависят от внешних runtime-сервисов. Все
ассеты входят в сборку; авторизация, БД, SMTP, файлы и CI/CD работают on-premise.
Репозиторий переносится прямым push либо Git bundle. Контейнерные образы собираются
в локальном GitLab Runner и публикуются в локальный Container Registry.

## Последствия

- требуется заранее учитывать закрытый dependency supply chain;
- внешние CDN и SaaS-интеграции запрещены;
- конфигурация полностью отделена от кода;
- deployment поддерживает контейнерный и классический варианты;
- инфраструктурные runbook'и являются частью релиза.
